개인정보처리방침 · Privacy Policy

시행일 · Effective: 2026-10-30

1. 접근하는 Google 데이터

  • Google Drive (drive.file): 앱이 직접 만든 "Medical Briefing" 폴더와 그 안의 브리핑 파일만 만들고 갱신합니다. 사용자의 다른 Drive 파일에는 접근하지 않습니다.
  • Gmail (gmail.compose): 사용자 본인 메일함에 브리핑 초안을 만들고 같은 초안을 갱신합니다. 메일을 발송하지 않으며, 기존 메일을 읽거나 검색·삭제하지 않습니다.

2. 저장과 이용

  • Google OAuth 토큰은 운영자 본인의 컴퓨터와 운영자 본인이 관리하는 실행 환경에만 저장됩니다.
  • Google API로 얻은 데이터는 위 목적(본인 계정에 브리핑 파일·초안 생성) 외에 사용하지 않습니다.
  • 데이터를 판매하거나, 제3자에게 제공하거나, 광고·사용자 프로파일링에 사용하지 않습니다. 사람이 Google 사용자 데이터를 열람하지 않습니다(운영자 본인이 자기 계정의 결과물을 보는 경우 제외).
  • 브리핑 내용은 PubMed 등 공개 학술 출처에서 온 것이며 개인 건강정보를 다루지 않습니다.

3. Limited Use 준수

Medical Briefing's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. 권한 철회 · Revoking access

언제든지 Google 계정 → 타사 액세스에서 Medical Briefing의 권한을 삭제할 수 있습니다. 철회하면 앱은 더 이상 Drive·Gmail에 접근할 수 없습니다.

5. 문의 · Contact

Google 동의 화면에 표시되는 사용자 지원 이메일로 문의해 주세요. / Please use the user-support email shown on the Google consent screen.

English summary

Medical Briefing is a single-user personal tool. It uses drive.file to create and update only the folder and files it creates, and gmail.compose to create and update briefing drafts in the user's own mailbox; it never sends mail or reads existing messages. OAuth tokens are stored only on the operator's own machines and execution environment. Google user data is not sold, shared with third parties, or used for advertising, and is used solely to provide this feature. Access can be revoked at any time at myaccount.google.com/permissions.
